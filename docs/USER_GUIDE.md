# Pickle Jar 使用手冊

> 這份是各功能的詳細用法。專案介紹、安裝、架構見 [README](../README.md)；版本變更見 [CHANGELOG](CHANGELOG.md)。

介面是「安靜的圖庫」：圖是主角，資訊在需要時才出現。左邊側欄分三區——**整理**（收件匣、待確認、未識別，有待辦時亮一個點，滑過看數字）、**瀏覽**（圖庫、角色、創作者、本子）、**收藏**（置頂、最近看過；智慧相簿存過才出現）；最下面是 NSFW 狀態（H）、**健康燈**（有事要處理時才出現：備份只在一顆硬碟、掃描暫停、背景工作失敗，點開看）、系統、設定。**每一頁同一個骨架**：上面是這頁是什麼（標題、一行說明、頁內分頁、「⋯」頁面動作），下面是同一條**查詢列**，選了圖就換成動作列；沒有查詢列的頁右上有一個放大鏡（Ctrl K、/）。連續按鍵時側欄、標題、工具列會淡出，動一下滑鼠就回來（設定 › 顯示 ›「專注退場」）；撤銷在每次動作後的提示裡（或 Ctrl Z），快捷鍵按 `?`。背景工作是主面板最上緣一條細線，點它看詳情。淺色／深色跟隨系統；底色預設是淡綠，想要白色到 設定 › 顯示 › 底色。點左上角標誌切換精簡或完整側欄。

本地執行的插畫／影片整理工具：用 **WD Tagger v3** 自動打 Danbooru tag、判斷分級；角色、創作者、作品以**搜源（Danbooru／Pixiv）最優先**，其他來源只當候選，你確認才算數。所有東西都在你的電腦上跑（只有你開啟的線上搜源會連網）。

## 安裝與啟動（Windows）

1. 雙擊 `start.bat`。**不用先裝 Python**：第一次會自動下載 [uv](https://docs.astral.sh/uv/)，在程式資料夾裡準備一份獨立的 Python 3.12 和套件（放在 `tools/`、`.venv/`，不影響電腦上其他的 Python），需要幾分鐘
2. 瀏覽器會打開 `http://127.0.0.1:7860/`，第一次會出現**設定精靈**：用資料夾瀏覽器挑圖庫資料夾 → 選模型 → 選線上功能與 NSFW 預設
3. 接著會在背景下載模型（eva02-large 約 1.2 GB），右上角有**下載進度**；下載很慢或失敗時，可以在設定填「模型下載鏡像」（例如 `https://hf-mirror.com`），或手動放模型：`models/SmilingWolf__wd-eva02-large-tagger-v3/model.onnx` + `selected_tags.csv`
4. 之後就能離線使用。套件版本固定在 `requirements.txt`，更新程式後如果版本有變，`start.bat` 會自動重新安裝

> **GPU**：預設裝 `onnxruntime-directml`，不用另外裝 CUDA，任何支援 DirectX 12 的顯卡（RTX 5060 Ti 也可以）都能直接用。想試 CUDA 就執行 `use-cuda.bat`，不行就 `use-directml.bat` 改回來。
> 不確定有沒有用到 GPU：Ctrl+K →「診斷」→「模型健檢／測速」，會顯示用的是 `Dml`／`CUDA`／`CPU` 和每秒幾張。

macOS／Linux：執行 `./start.sh`（有裝 uv 就用 uv，沒有就用系統的 python3）。

## 運作方式

```
新檔案 ─(監看/定期掃描)→ 解碼＋縮圖＋dHash＋內容指紋 ─→ WD Tagger v3 ─┬→ 一般描述 tag（可搜尋）、媒材
                                                                       ├→ 分級 → NSFW
                                                                       └→ 角色 → 候選（AI 模型；搜源找到就收掉）
Danbooru（原檔 MD5／Pixiv ID／推文 ID）─→ 直接確認        ← 最優先
Danbooru（IQDB 相似圖）─→ 候選第 1 順位
Pixiv（作者 → 候選；標籤推的角色、作品只記下）
WD Tagger v3 ─→ 候選第 3 順位（Danbooru 找到結果就收掉）
                      ↓
               待確認 ─(你按「是」)→ 正式的角色／創作者／作品標籤
```

- **一般描述 tag**（長髮、制服…）：分數高於門檻才寫入，直接可以搜尋。
- **身分標籤**（角色／創作者／作品）：一律先進「待確認」，詳見下方〈待確認（候選）與可信度〉。
- **舊版的「整張圖相似度推薦」已移除**：它把畫風、同框角色當成線索，推薦出來的多半是不相干的圖。現在整張圖特徵只用在「否決傳播」（你說不是 X，很像的圖也不會再被自動標 X）。
- **新的先處理**：一次丟進大量圖片時，最新的檔案先標記，馬上就能看到；右上角會顯示進度和預估剩餘時間，可以**暫停／繼續**。
- **格式**：JPG／PNG／WebP／GIF／AVIF，iPhone 的 **HEIC／HEIF** 也可以；iPhone 原況照片附帶的 `.MOV` 會自動略過（設定可關）。
- **影片**：均勻抽 4–12 幀一起標記後彙總；只要有足夠多的幀被判為 NSFW，整支影片就標成 NSFW。
- **重複**：只算**看起來一模一樣**的圖（解析度、格式不同）和**局部截圖**；改了表情、對話框換字、打碼的差分**不算**。先用外觀指紋找候選，再逐像素比對（容許 2 像素的位移和縮放誤差，找「差最多的一小塊」）。局部截圖會標「第 N 張的局部」、不會被建議保留（背景比對，第一次約 10 秒）。每組標出「建議保留」（完整、解析度最高、已整理最多、有來源），可以**並排比較**（滑鼠移到圖上兩邊同步放大同一個位置），刪除時會移到資源回收筒。
- **大圖**：滾輪縮放、拖曳移動、雙擊或按 **Z** 放大到原始尺寸；影片可以用「系統預設程式開啟」（你習慣的播放器）。

## 介面的五個關鍵操作（2026-10 改版）

- **查詢列**（圖庫、未識別…）：目前的條件是一顆顆 token（例如「狀態 缺創作者」「媒材：漫畫」），× 拿掉。點查詢列會展開**分面**：狀態（完全未識別／缺角色／多人圖缺角色／缺創作者）、分流、分堆、依作品、缺作者的、範圍（影片、NSFW、官方截圖、重複、作品與標籤…）、媒材，都附張數；打字會篩分面，Enter 把打的字加進搜尋（語法照舊）。右邊「≡」是排序、原比例／方格、縮圖大小、全選。
- **排序**：最新加入、**最近操作**（你最近確認、否決、加標籤、略過、改 NSFW、用 ascii2d 查過…的圖在最前面，沒動過的在最後；否決時連帶清掉的相似圖不算）、最舊、拍攝時間、解析度、路徑、隨機。旁邊的「↓ 正序／↑ 倒序」把任何排序**整個倒過來**（會記住）：例如最近操作的倒序，是沒動過的在前、最近動過的在最後。合併、刪除、停止自動標註這種對標籤做的事不算動了那些圖。
- **透視**：格子平常沒有任何角標（影片只留一個小 ▶）。按住 **Alt**（或按查詢列旁的「透視」）時，媒材、NSFW、時長、候選來源一起浮出來，放開就消失。
- **命令膠囊**：選圖後底部只露出這一頁最常用的 3 個動作（例如缺創作者頁是「＋創作者 R／不用再找作者／不用整理 L」），其餘 20 個打一兩個字就找到（「補」→ 補跑），或按 ⋯ 看全部。你在某一頁常按的動作會自己擠進前 3。沒選圖時，字母鍵和數字鍵作用在**滑鼠指著的那張**。
- **大圖**：圖下面一行字幕「角色 · 角色 — 創作者 · 作品」，候選是綠字加「？」（Enter 是、⌫ 不是、Shift+Enter 全部是）；★ ✕、＋角色／＋創作者／＋作品／＋標籤 滑過字幕才出現。快速標籤的按鈕在詳細抽屜最上面；NSFW、官方、來源、以圖搜圖、描述標籤、AI 生成資訊、處理紀錄、檔案收在右邊的**詳細**抽屜，按 **I** 開關（會記住）。
- **整篇 Pixiv 作品逐頁標角色**：Pixiv 的標籤是整篇共用的，多頁、多角色的作品每一頁都會被標上全部角色。這種圖的大圖角色欄下面有「整篇貼文 N 頁：逐頁標角色」（否決 Pixiv 標的角色時，提示裡也有「逐頁整理」）：一張表，每一列一頁、每一欄一個角色，點格子切換 ✓ 是／✕ 不是（Shift+點＝清掉），欄位標題的「全 ✓」「全 ✕」整欄一起改，滑到縮圖上看大圖，也可以加一個角色欄。按「存」一次寫進去，Ctrl+Z 一次還原
- **大圖的鍵盤**（2026-10-02 起）：**Enter**＝第一個候選「是」、**⌫**＝「不是」、**Shift+Enter**＝這張的候選全部是（多人圖一次標完）；**Shift＋數字**＝第 N 個候選「是」、**Alt＋數字**＝「不是」（候選前面的小數字；數字鍵本身還是快速標籤）；**A** 加角色、**R** 創作者、**G** 標籤、**B** 本子、**O** 原創、**L**／**X** 不用整理、**N** NSFW／安全切換、**K** 官方、**S** 搜來源、**I** 詳細抽屜、**Delete** 刪除這張（會先問，刪掉後接著看下一張）。在**待確認頁**看大圖時，這張的候選都處理完（多人圖也沒有人還沒標）就**自動跳下一張**，提示裡可以「回上一張」；在圖庫等其他頁面會留在這張，自己按 → 換下一張。本體＋造型（例如白上こより＋白上こより（初期衣裝））都是候選時合成一列，確認造型就一起確認本體。
- **待確認・專注模式**（預設）：一個問句「這是 ○○ 嗎？」＋大圖；滑過名字看你確認過的圖，點「角色 ▾」換一個名字。Enter 是、⌫ 不是、L 略過、C 換成、A ＋角色、Delete 刪除、Space 看大圖；多人圖確認後原地問「還有誰？」（Enter＝標完了）。AI 高分的同名候選用**整批看**一面看完；需要多選時切到**網格**（模式在標題下）。

## 收件匣與系統

**收件匣**（首頁）：一句話告訴你要做什麼＋一顆主按鈕（Enter），下面是「之後可以做」、智慧相簿、最近加入。

**系統**（側欄下方）：
- **找出處的流程圖**：上面四個數字（張數、找過出處、找到出處、還沒有身分），下面照新圖真正跑的順序，每一步一條長條＝你的圖庫在這一步找到多少。點一步打開那一步的設定（設定 › 自動標記與搜源）；ascii2d、畫師作品比對在那一列「打開」
- **工具**（分組）：找出處（補跑舊圖）／整理（換成高清版、重複的圖）／把圖收進來（從網站匯入、手機／平板）／維護（背景工作、備份與還原、**操作紀錄**、系統狀態）；很少用的（從畫師反推、篩選非動漫圖、標籤蘊含、匯出訓練集）在「更多工具」；準確率抽查在「系統狀態」，Ctrl K 都叫得到

**找出處的步驟**：大圖 › 詳細（I）裡的時間軸，列出這張圖自動跑過哪些步驟、各自的結果（例如「e621 原檔：查過，沒有」「以圖搜圖：略過（預判不太可能在 Danbooru 上）」），找到出處後其他步驟就不再做。

## 搜尋、指令面板與智慧相簿

按 **Ctrl+K** 或 **/** 打開指令面板，一個框可以做所有事：
- 打角色名（中文、日文、英文都可以）→ 直接跳到角色頁
- 打條件 → 搜尋圖片，例如 `hatsune_miku rating:safe ratio:portrait`
- 名字怎麼打都可以：畫面上看到的中文名（繁體或簡體都行，例如「芙莉蓮」）、日文名、英文名加空白（`blue archive`、`hatsune miku`）、底線寫法都找得到同一個角色或作品
- 搜作品（`蔚藍檔案`、`series:blue_archive`）＝作品頁的那些圖：直接標了作品的圖，加上角色屬於這部作品的圖。書架、作品與標籤頁、搜尋選單上的張數都是這個數字，不會重複算多人圖
- 搜不到東西時，畫面會說是哪個字找不到，並列出「你是不是要找」
- 打「掃描」「暫停」「診斷」「手機」「備份」「設定」等 → 執行指令

| 語法 | 意思 |
|---|---|
| `hatsune_miku`、`初音`、`雙馬尾` | 標籤、角色的中日文名、常見一般 tag 的中文 |
| `-tag` | 排除 |
| `a\|b`、`a OR b` | 任一個 |
| `*_(arknights)` | 萬用字元 |
| `rating:safe`、`rating:nsfw`、`rating:q,e` | 分級 |
| `type:chibi`、`type:cosplay`、`is:video`、`is:multi`（多人） | 媒材／種類 |
| `date:2024`、`date:2024-05`、`date:2023..2024-06`、`added:7d` | 拍攝（或檔案）時間、加入時間 |
| `w:>=1920`、`h:<800`、`ratio:portrait`、`ratio:>1.5` | 尺寸、比例 |
| `chars:>=2` | 已確認的角色數 |
| `path:桌布`、`series:project_sekai`、`src:none`、`src:pixiv`、`is:noartist`、`is:candidate` | 資料夾、作品、來源、缺創作者、有候選 |

搜尋後，頂列會出現搜尋條件的膠囊，按書籤圖示就能**存成智慧相簿**：它會一直套用這個條件，新進的圖符合就自動出現在裡面（側欄完整模式、首頁、指令面板都找得到）。

圖庫預設**依原比例排列**（像相簿，直圖橫圖都不裁切），也可以切回正方形；只會畫出看得到的那幾列，幾萬張也能順順捲。


## 角色書架

「角色」頁是書架式的瀏覽：
- **概況**：「收藏排行」（依確認張數的排行表，長條是跟第一名比）、「近期新增」（近 7 天加進圖庫的圖裡有這個角色，+N 是幾張；看的是加進圖庫的時間，不是檔案日期），以及依張數排列的**作品**（每部作品一格，裡面拼四張封面）
- 標題下的分頁切換 **概況／近期新增／依作品／跳到作品**；找角色的輸入框在下面的查詢列；書架／列表、中文名整理、抓名字在 ≡
- **作品頁**：作品封面、角色數、張數、近 7 天新增，角色依張數分成「主力（20 張以上）／常見（5–19 張）／零星（1–4 張）」，也可以一鍵「在圖庫裡看全部」
- **書架／列表** 兩種顯示方式
- 側欄預設是完整側欄（會顯示置頂和最近看過），點左上角的標誌可以切換成精簡的圖示列
- 作品封面會用高解析縮圖（第一次顯示時產生）
- 搜尋框可以用中文、日文、英文找角色或作品
- **中文名（Bangumi）**：Danbooru 沒有中文別名、或中文別名是暱稱／錯的（常闇トワ→「常盤香菜」、湊あくあ→「阿夸」），程式會用角色的**日文名**到 Bangumi（番組計畫）找中文名，簡體自動轉繁體。名字完全一樣才用；同名好幾個時要對得上你圖庫裡的作品，對不上就不換、放進「同名好幾個，你挑」。純漢字、中文也通的別名（原神這類中國遊戲）不拿去查，Danbooru 的名字比較完整時（千夏蕾米爾 vs 千夏）留著 Danbooru 的。新角色抓完資料卡會自動查（可以關）
- 也查 **Wikidata**：很多角色有台灣譯名（安妮亞·佛傑、達爾、常闇永遠），有台灣譯名就優先用；同名的看說明裡寫的作品
- **校對表**：2026-10 把有確認圖的角色、作品譯名全部校對過一次（台灣譯名優先），校對過的名字優先，之後重查不會被換掉；改掉的在「中文名整理 › 校對改過的」
- 顯示順序：你取的名字 > 校對表 > 寶可夢官方譯名 > Wikidata 台灣譯名 > Bangumi > Wikidata 其他中文 > Danbooru 中文別名 > **英文**（沒有中文時不顯示日文）。作品：你取的 > 校對表 > 內建台灣譯名 > 維基百科台灣譯名 > Bangumi > Danbooru
- **造型**（minato_aqua_(1st_costume)、mika_(swimsuit)_(blue_archive)）：用本體的中文名＋造型，例如「湊阿庫婭（初始服裝）」
- **中文名整理**：角色書架的 ≡ ›「中文名整理」（或 Ctrl+K 打「中文名」），角色和作品都可以整理：
  - **校對改過的**：校對表改掉了什麼（原本 → 現在），不喜歡按「改回」
  - **新的角色要校對時**（下面那行「新的角色／作品還有 N 個沒校對」）：按「複製清單給 Claude 校對」（一次最多 150 個，圖多的先，說明已經寫在裡面）→ 貼到任何 Claude 對話 → 把回覆整段複製，按「貼上校對結果」貼上、按「存」。Claude 不確定的會寫 -（看過、沒中文名，照舊顯示英文）。建議新角色累積幾十個時做一次
  - **Bangumi 自動換的**：換掉了什麼（原本 → 現在），不喜歡按「改回」或點別的；看過按「好」（沒看過的排前面）
  - **同名好幾個，你挑**、**沒有中文名**（點候選或直接打名字 Enter）、**有好幾個譯名**、**你取過名的**（可以恢復自動）
  - 下面可以「現在查／全部重查」、關掉「新角色自動查」
- **寶可夢**：物種名用官方台灣譯名（沙奈朵、路卡利歐…，內建 PokeAPI 的資料，不用連網）；確定是寶可夢才套用
- **中文名稱**：從 Danbooru 別名挑出中文名並自動轉成繁體。會跳過日文漢字寫法（竜華、呪術廻戦）和 Pixiv 標籤（○○同人、畫師周榜），挑不到中文就用日文。設定裡可以改成日文或原始 tag，也可以在標籤頁的 ⋯ 選單自己取名
- **作品名稱**：手動取的名字 > 內建的台灣譯名表（約 220 部常見作品）> 維基百科查到的台灣譯名 > Danbooru 別名。維基只在「日文名跟日文維基條目完全同名」時才採用，被導向到別的條目、消歧義頁一律放棄，寧可顯示日文也不要查錯；只送出作品名稱，不會送出圖片
- **作品頁**：在角色書架點任何作品（或角色頁上的作品標籤）會打開作品頁：上面是作品資訊和這部作品的**角色列表**，下面就是這部作品的圖庫。點一個角色＝只看他的圖，再點一次取消；雙擊打開角色頁。作品名稱可以在作品頁按「改名」
- **同系列合併**：書架上 FGO 併進 Fate 系列、MyGO 併進 BanG Dream!、Limbus Company 併進 Project Moon（只併到你圖庫裡本來就有的母系列）。「誰是誰的子作品」來自 Danbooru 的 tag implication（人工審核過的關係），新作品也會自動處理；沒連網時退回用名字判斷
- **作品頁包含**：標了作品 tag 的圖、子作品的圖，以及只標了角色（角色屬於這部作品）的圖。角色列最後面淡淡的「待確認 N」是還沒有確認過圖的角色，點一下到角色頁確認；打開子作品的頁面會自動轉到母系列
- **造型**：`mika_(swimsuit)_(blue_archive)` 這類泳裝、制服等造型會併進角色本體，卡片上會標「N 個造型」
- **封面**：角色頁（創作者頁也一樣）標題旁的 ⋯ ›「自選封面」→ 從這個角色確認過的圖挑一張；或在大圖檢視裡按角色／創作者標籤旁的 ★。角色頁背景、書架、列表都會用這張，「恢復自動」可取消
- **作品封面**：書架上每部作品疊三張圖，一定是三張不同的圖（多人合照同時是好幾個角色的封面時，會換成角色的下一張）。想自己選：滑到作品卡上按右上角「換封面」、作品頁的「封面」，或大圖檢視裡作品標籤旁的 ★；選的那張放第一張，另外兩張自動挑。「恢復自動」可以取消
- **依作品**：書架上方「依作品」分頁可以依張數／最近新增／角色數／名稱排序，置頂的作品排最前面。總覽只列前 12 部
- **自建角色對上 Danbooru**：你自己建立的角色（例如「瑞希」），如果 Danbooru 上有別名相符的角色，頁面上方會提示，一鍵合併成正式名稱。合併後舊名稱會自動導向新名稱，之後任何來源產生舊名稱也會直接歸到新名稱

## 快速標籤（梗圖、真人、截圖）

> **梗圖、截圖不認角色**（設定 › 不認角色的標籤）：標了這些的圖不再列角色候選給你確認、不推薦角色、不自動上傳以圖搜圖；加上時還沒決定的候選會拿掉，Ctrl+Z 可以還原。已經確認的角色不動。

比起 1girl、long_hair 這種描述，你天天用的是「梗圖」「真人」這種分類，所以它們有自己的一鍵按鈕：
- **數字鍵 1–9**：選取的圖（沒選就是滑鼠指著的那張）、或大圖裡正在看的那張，按一下加上，再按一下拿掉
- 按數字鍵時畫面中央會閃一下（例如「1 梗圖 ✓」），可以點「復原」。選取列、大圖「詳細」最上面也有按鈕；要看某個快速標籤的全部圖，Ctrl K 打名字
- 加上「梗圖／真人／截圖」的圖會同時離開「未識別」（不用再認角色）；不會刪掉 AI 的角色候選（cosplay 照片還是可以標角色）。拿掉標籤會回到未識別
- 標籤頁上會提示「AI 覺得還有 N 張可能是真人／梗圖／截圖、還沒標」，按「看一看」一次把它們列出來，選一選按數字鍵就好
- 標過 50 張以上的快速標籤，「AI 覺得」是**從你標的圖學出來的**（每次標完約 2 分鐘後重學；也可以搜尋 `guess:表情包`）。你拿掉的不會再被建議；標得越多越準
- 要改成別的（例如加「表情包」「喜歡」）：設定 › 顯示 ›「快速標籤」。最多 9 個，順序就是數字鍵
- 都是普通的自訂標籤：搜「梗圖」、`tag:真人`、`-tag:梗圖`（還沒標梗圖的）都可以；每次加／拿掉都能撤銷

## 手機／平板看圖庫
1. 電腦上：系統 › 工具 ›「手機／平板」→「開啟手機／平板連線」→ 重新啟動程式（Windows 第一次會問防火牆，請允許「私人網路」）
2. 手機或平板跟電腦連同一個 Wi-Fi，用相機掃視窗裡的 QR code，輸入 PIN
3. 按「看圖庫」：圖庫、角色、創作者、本子都能看；大圖左右滑換張、往下滑關閉、兩指縮放、點兩下放大。同一頁也能「上傳到圖庫」
- 手機上只能看和上傳；確認、刪除、改名這些整理的動作請在電腦上做。帳號金鑰、設定、備份、匯出不會給手機
- PIN 輸入一次可以用 30 天（程式重開也不用重新輸入）；覺得外流了就在視窗裡「換一組」，舊的登入全部失效
- 電腦要開著、程式要在跑；只在同一個 Wi-Fi 裡有效

## 分享到 QQ、Messenger
選好圖按 **Ctrl+C**（或選取列的「分享」、大圖右上的分享鈕），到 QQ 或 Messenger 的聊天視窗按 **Ctrl+V** 就貼上了。沒選圖時 Ctrl+C 複製滑鼠指著的那張；大圖裡是眼前這張。
- 放進剪貼簿的是**原檔**（跟在檔案總管按 Ctrl+C 一樣）：GIF 會動、影片也可以、一次可以好幾張（最多 50 張）
- 只選一張圖時，另外也放一份「圖片」：網頁版 Messenger 這種只收圖片的地方也貼得上
- HEIC、AVIF、TIFF、WebP 聊天軟體常常不收，會先轉成 JPG（有透明的轉 PNG）再放進去；原檔不動
- 提示裡的「開 Messenger」會打開 messenger.com
- 有反白文字時 Ctrl+C 照常是複製文字；手機的只看模式沒有分享

## 影片轉 GIF
大圖看影片時，右上角的底片按鈕「轉成 GIF」。
- **最快**：**Shift＋點**底片按鈕，或按 **Ctrl+Shift+C**：不開視窗，用上次的設定把整部影片轉好，直接放進剪貼簿，到 QQ／Messenger 按 Ctrl+V。整部超過 2 分鐘、或轉出來會太大時，會改打開視窗讓你選一段
- **選一段**：拖時間軸上綠色那段的兩端（拖中間＝整段移動），或播到想要的地方按 **I**（開始）、**O**（結束）；也可以直接打秒數。Space 播這一段（會循環）、←→ 一格一格、Shift+←→ 一秒。打開時：20 秒以下的影片選整部，比較長的從現在播到的地方取 10 秒
- **每秒格數** 10／15／20／24、**寬度** 320／480／640／原尺寸（不會放大）、**顏色**：「平滑」抖色，漸層、照片比較順；「乾淨」不抖色，動畫風的大色塊比較乾淨、檔案也比較小
- **做好後**：「直接複製」（預設）／「直接存」／「先看看」。選直接複製或直接存，按一次 Enter 轉好就完成，再按 Enter 關掉視窗。這些選擇都會記住
- 一次最多 2 分鐘；下面會顯示幾格、多大，可能超過 10 MB 時會提醒（GIF 很大：480 寬、15 格，十幾秒就可能超過 10 MB）
- 選「先看看」的話，做好先給你看，再選：
  - **存進圖庫**（Enter）：放在影片旁邊，檔名「影片名_開始-結束.gif」；影片已確認的角色、創作者、作品、自訂標籤（含快速標籤）和你手動設的 NSFW 一起帶過去，接著跟新圖一樣標記
  - **複製分享**：直接放進剪貼簿，到 QQ／Messenger 按 Ctrl+V（不用先存）
  - **下載**、**重新調整**
- 沒存的 GIF 一天後自動清掉；瀏覽器播不了的影片（iPhone 的 HEVC）也能轉，直接輸入秒數

## 刪除作品
不是作品的作品標籤（AI 常把 Twitter、YouTube、NBA 當成作品）：作品頁標題旁的 ⋯ ›「刪除作品」，或在待確認看到它時按「刪除這個作品…」。會從所有圖上拿掉、以後不再自動標上；底下的角色不會刪。按撤銷可以整個還原。

## 本子（同人本、cos 圖包、畫集）

一整本同人本、一套 cos 圖包這種「獨立作品」，每一頁 AI 和搜源都很難認，一張一張標作者、角色太累。本子把它們當一本：
- **建立**：側欄「本子」頁下方會列出「可能是一整本的資料夾」（圖多、檔名連號、不是按月份分的），點一下建立；或在任何地方選圖後按 **B**
- **資料夾名自動拆**：`(C104) [社團 (作者)] 標題 (作品) [中國翻訳]` 這種名字會拆出作者、作品，圖庫裡已經有的預設勾選，新的要你自己勾
- **整本的標籤**：本子頁上「＋ 作者／角色／作品／標籤」，會加到每一頁（之後加進來的頁也會）。拿掉整本的標籤、移出頁、解散，都只拿掉「因為本子才加上的」，你自己在單頁上標的不動；你否決過的也不會被蓋掉
- **翻頁**：本子頁依頁序排列，「▶ 從第一頁看」打開大圖，←→ 就是翻頁；大圖會顯示「在哪本、第幾頁」
- **頁序**：建立時自動用智慧排序。要換：「排頁序…」選一種、看預覽（會分成幾本、前幾頁、動到幾頁）再套用，Ctrl+Z 可撤銷
  - 智慧排序：好幾個資料夾（好幾本）合成一本 → 先分本，本照集數（名字裡的 1、2、3、第三卷…；「完」「最終」排最後、「番外」再後面；看不出集數的照上傳順序），每本裡照檔名 1、2…10。手機照片（圖庫\2025-02 這種按月份的資料夾不算一本）照 IMG_xxxx 編號，編號用完從 0001 重來的接在 9999 後面；影片這種沒有編號的，插在時間最接近的那張後面
  - 依檔名（不分資料夾）、依拍攝時間（沒有就用檔案時間）、依加入時間、整本倒過來
  - **手動調整**：所有頁的縮圖，拖曳換位置；點選、Shift 連選、Ctrl 加選，可以一次拖好幾張；或選好後「移到最前／最後／第 N 頁前」。雙擊打開大圖。按「儲存頁序」才生效
- **好幾本合成一本**：上方列出目錄（點一本＝從那本第一頁看），圖之間在換本的地方有分隔。頁序交錯（各本的第 1 頁排在一起）時不畫分隔，改成提醒＋「智慧排序」按鈕
- **Pixiv 多頁作品存成本子**：照頁序（p0、p1…）整理成一本、書名用作品標題、整本標上作者（Danbooru 還沒登記的作者用 Pixiv 暱稱建立）。預設不自動，由你決定：匯入結果上按「存成本子」、大圖上按「整篇存成本子」（以前存的作品也可以）、瀏覽器腳本（3.3 以上）選頁時按「整篇存成本子」；還有頁在標記時，標完會自動整理進去。想自動的話：設定 › 從網站匯入 ›「Pixiv 多頁作品」選「漫畫自動存成本子」（Pixiv 上作者標成漫畫的）或「多頁都自動存成本子」。同一篇之後補存的頁會加進同一本
- 搜尋：`album:12`（某一本）、`album:標題`、`is:album`／`is:noalbum`。每個動作都能撤銷
- **不在圖庫、角色頁、作品頁裡**：本子的每一頁平常不列在圖庫和角色／創作者／作品頁（頁尾會寫「另 N 張在本子裡」），到「本子」整本看；搜尋照樣找得到。想一起看：≡ 選單勾「也顯示本子裡的頁」
- **隔絕**：本子裡的圖不會自動推角色／作者／作品、不會被送去搜源（Danbooru／Pixiv、ascii2d、畫師作品比對、PixAI），也不在「未識別」的待辦裡——身分由整本的標籤決定。描述標籤、NSFW 分級照常。放進本子時，那些圖上還沒確認的自動候選會拿掉（可撤銷）；已經確認、否決過的不動。想讓某張圖重新被自動找，把它移出本子
- 以前的「同一組圖」自動判斷已經移除（不夠可靠）；本子是你自己決定的，所以可靠

## 缺創作者、缺角色的整理

- **作者不可考**：表情包、梗圖這種轉了好幾手、找不到作者的圖，有兩種處理：
  - 標「梗圖」「表情包」「截圖」這類標籤（快速標籤按 1 就好）→ 自動不算缺創作者。哪些標籤算，在 設定 › 顯示 ›「不用找作者的標籤」改；標籤拿掉就回來
  - 其他個別的圖：選取後按選取列的「不用再找作者」（任何頁面都有，例如作品頁「沒標作者」），或大圖創作者欄的「作者不可考」。之後還是可以標作者
  - 搜 `is:artistdone` 看全部作者不可考的圖
- **原創作品／AI 生成**：缺創作者頁有這兩個分流。AI 生成是讀檔案裡 ComfyUI／Stable Diffusion／NovelAI 留下的資料判斷的（大圖會顯示「AI 生成（ComfyUI）」），可以整批「不用找作者」或「全部找作者」
- **依作品**：缺角色、缺創作者頁列出「蔚藍檔案 12、原神 5…」，點一下到作品頁、只看那部作品裡還沒標角色／作者的圖；作品頁上也有「沒標角色 N／沒標作者 N」
- **官方作品**：動畫截圖、漫畫截圖、小說插圖、電影截圖都算已經有作者，不會出現在「缺創作者」和「完全未識別」；圖庫的「官方截圖」分頁可以找到全部（再分動畫／漫畫／小說／電影）
- **多人圖**：角色是 Danbooru／Pixiv 標的圖，WD 多數到的人當作路人，不再提醒「還有人沒標」
- **AI 生成的圖**：檔案裡的生成資料會讀出來，大圖有「AI 生成資訊」：模型、LoRA、種子、步數、提示詞（可複製）、負面提示詞。點模型或 LoRA 可以找用同一個的圖
  - 提示詞裡寫了你圖庫認得的角色或作品（例如 `hatsune miku`、`wakaba mutsumi \(bang dream!\)`）→ **直接確認**。想改回自己看：設定 › 自動標記與搜源 › AI 生成提示詞 選「放待確認」，會進待確認的「生成提示詞」分頁
  - 搜尋：`prompt:hatsune_miku`、`model:animagine`、`lora:xxx`、`is:aigen`
- 搜尋：`is:nochar`、`is:missartist`、`is:aigen`、`is:artistdone`

## 不用整理（以前的「排除」、「略過」）

梗圖、截圖、日常照片這類不想整理身分的圖，選取（或滑鼠指著）按 **L**（或 X）「不用整理」：圖留在圖庫，但不再出現在未識別、待確認的待辦，AI 的身分候選也拿掉。未識別 › 面板的「不用整理的」可以放回待辦。（2026-10-07 起「排除」併進這裡。）

## 待確認（候選）與可信度

**整批看**（左上角「整批看／專注／網格」）：AI（PixAI、WD）分數 ≥ 0.9（可以改成 0.95／0.85／0.8）、不像梗圖的候選，同一個名字排成一面。預設全部「是」，看到錯的點一下變「不是」（AI 會記住），再點一下變「略過」（角色沒認錯、但不想標）。滑鼠指著也可以按 ⌫／L，Space 開大圖；Enter 送出這一面，自動換下一個名字。分數低的排在前面（最可能錯的先看到），上方有已確認的參考圖可以對照。送出整面是一筆撤銷。
分數低於門檻的、像梗圖／截圖／照片的不在這裡，在「專注」逐張看（兩邊不會重複）。


角色、創作者、作品是**身分標籤**，只有你確認過的才算數。自動找到的一律先放進側欄的 **待確認**，按「是」才會變成正式標籤。所以角色頁、搜尋、未識別這些地方，只會用到你確認過的標籤。

候選依可信度排序，越上面越可信：

| 順位 | 來源 | 處理方式 |
|---|---|---|
| 1 | **Danbooru・原檔**：Danbooru 原檔 MD5 完全相符；檔名是 Pixiv 作品 ID，Danbooru 上有同一個作品；檔名帶 X（Twitter）推文 ID，Danbooru 上有來源是這則推文的貼文 | **直接確認** |
| 2 | **Danbooru**：IQDB 相似圖 ≥ 90% | 候選，排最前面 |
| 3 | **Pixiv**：Pixiv 作者；Pixiv 標籤對應到的角色、作品 | 作者是候選；標籤推的角色、作品預設「只記下」（Pixiv 標籤是整篇共用的，常常不準），設定 › 自動標記與搜源 › Pixiv 可以改回候選 |
| 4 | **你的圖庫**：跟你確認過的圖很像（見下） | 候選（「你的圖庫」分頁） |
| 4 | **WD Tagger v3**、**PixAI** | 候選，參考就好（Danbooru 找到結果就收掉；PixAI 預設只記下） |

**你的圖庫（新角色辨識）**：（2026-09-30 重新驗證，避免倖存者偏差：從「你的圖庫」確認的圖不拿來算；另外看單人／多人圖、WD 不認得的角色、學不到的角色會不會亂推薦）WD Tagger 不認得的角色（若葉睦、自創角色…）用**你確認過的圖**來推薦。新圖跟你確認過的圖比整體特徵：最像的 10 張投票，再跟每個角色的「平均樣子」比一次，兩邊都指向同一個角色、票數夠集中才推薦。每張推薦右下角有「跟你確認過的哪幾張很像」的小圖。只進待確認，你按「是」才算；否決過的不會再推薦。確認得越多會越準。**會從你的是／不是學習**：你否決過的那類圖（例如某個角色的梗圖、截圖）之後就不會再推；按完約 3 秒自動重算，待確認頁會自己補上新推薦、拿掉收回的，不用重新整理。按過的是／不是少於 40 筆時只用規則。實測（每張確認過的圖假裝沒標過來猜，同一個資料夾的不算）：推薦的 **99.3% 是對的**，能認出約 40%；WD 不認得的角色 98.6%。可在「系統狀態」旁的 `/api/diag/eval-knn` 重新驗證。

- 為什麼以 Danbooru 為主：SauceNAO 的 Pixiv 索引大約從 2023 年底就沒再更新，新作品查不到；Danbooru 則更新得很及時，連最近保存的 X 圖也查得到。所以本程式直接查 Danbooru（原檔 MD5、Pixiv ID、推文 ID、IQDB 相似圖），Pixiv 只用來補作者和標籤
- **搜源最優先**：一張圖只要搜源找到結果，AI 模型的角色候選就會收掉（設定可關）；找到角色清單時，其他來源推薦、但不在清單裡的角色也不會出現在候選。
- **一次確認一個角色**：待確認頁上方選一個角色，會列出這個角色**已確認的參考圖**，對照髮型、瞳色、配件，比一張張猜快很多。
- **略過 L**（待確認頁）：角色沒認錯、但這張不想標（梗圖、日常截圖剛好有角色）→ 拿掉這張的 AI 角色候選，之後也不再推薦。跟「不是 ⌫」不同：不會讓 AI 學到「這不是 X」，也不會連帶拿掉相似圖上的 X；可以撤銷。找到出處的候選不受影響
- **高信心 AI 候選先檢查再確認**（網格的 AI 模型分頁；現在多半用「整批看」）：上方會用**你自己過去的確認／否決紀錄**算準確率（例如「信心 ≥ 97% 的，你確認過 716 筆、否決 2 筆，99.7%」）。因為你可能只確認了對的、梗圖還沒處理，所以不會盲目全部確認：先分成「像插畫」和「可能是梗圖／截圖」（有假截圖、中文字、聊天紀錄、卡牌等描述的）兩批，點進去看一遍，不要的按 L 略過，剩下的一次確認；可以撤銷。過去至少 50 筆、準確率 ≥ 98% 才會出現。**動漫圖和 furry 圖分開算**（AI 是用動漫圖訓練的，furry 圖上的準確率要看你自己的紀錄）
- 「找到出處」分頁（Danbooru、e621、Rule34、圖上簽名）裡可以再按來源篩選；沒有 Pixiv 候選時 Pixiv 分頁會隱藏
- 待確認・網格依順位分成「找到出處／Pixiv／生成提示詞／你的圖庫／AI 模型（WD、PixAI）／全部」，建議從找到出處開始（沒有候選的分頁會藏起來）；目前分頁是空的會自動跳到第一個有東西的分頁。在待確認頁看大圖時，按 ✓ ✕ 或 Enter／⌫ 處理完這張的候選會自動跳下一張（其他頁面不會跳）。可以多選後按 Enter（是）或 ⌫（不是），也可以把滑鼠移到圖上直接按 ✓ ✕。
- 角色頁的「全部／已確認／候選／已否決」在下面查詢列的面板「狀態」。
- 每一種來源「找到時怎麼辦」（直接確認／放待確認／只記下）和門檻在 設定 › 自動標記與搜源 改（見下面那一節）。
- **Pixiv 標籤對應**：大圖檢視的 Pixiv 區塊裡，點一個 Pixiv 標籤（例如「暁山瑞希」）指定它是哪個角色，之後所有帶這個標籤的 Pixiv 作品都會自動對上。

## 官方作品：動畫截圖、漫畫截圖、小說插圖、電影截圖

跟媒材分開記的「官方」種類：
- **怎麼標**：選取後按 **K**（官方…）選動畫截圖／漫畫截圖／小說插圖／不是官方；大圖檢視的「官方」列也可以改。可以撤銷
- **不算缺創作者**：動畫、漫畫截圖沒有同人意義上的畫師，標了作品＋角色就算整理完；小說插圖的插畫家照常當創作者（Danbooru 找得到就會帶出來）
- **篩選、搜尋**：媒材選單的「官方作品」、`type:anime`、`type:manga`、`type:novel`、`is:official`
- **Danbooru 標了** `anime_screenshot`、`novel_illustration` 等 → 自動設成對應種類
- 你手動設定的一律優先，自動判斷不會蓋掉

## 媒材

每張圖會自動判斷媒材：插畫、Q 版、漫畫、3D、Cosplay、真人照片、公仔／娃娃、截圖／文字（聊天紀錄、貼文、手機畫面這類），按住 Alt 時縮圖左下角會浮出來，查詢列面板的「媒材」可以篩選。真人和公仔照片不做整張圖相似度推薦；AI 模型在這兩類給出的角色也只當參考。

**AI 從你標的學（b77）**：
- **改媒材**：選圖按 **M**（再按數字 1–8 直接選），或大圖 › 詳細 ›「媒材」列。你標的一律照你的，之後重新標記也不會蓋掉；「自動」可以拿掉你標的。可以撤銷
- **AI 會重新學**：你標完約 3 秒，AI 用你標過的圖重新訓練，整個圖庫重算一次（約 2 秒）。**一開始要先標約 40 張（每一種至少 3 張）AI 才會開始學**，在那之前用簡單的規則判斷；標得越多越準，尤其是 3D、Cosplay、公仔這幾類
- **CLIP（b78）**：除了 WD，再用一個看一般圖片的模型（CLIP）一起判斷，3D、公仔、Cosplay 分得比較準。第一次開程式會下載約 350 MB、把整個圖庫算一遍（跟 WD 一樣用顯示卡；萬一用顯示卡時程式崩潰，下次開程式自動改用 CPU。CPU 約半小時，背景工作看得到進度）；之後只算新圖。在 設定 › 自動標記與搜源 ›「媒材（CLIP）」可以關
- **沒把握的不亂分**：篩選某一種媒材時，只列你標的和 AI 有把握的（信心 ≥ 60%）。沒把握的集中在媒材選單最下面的「**未定**」（搜尋 `type:unsure`）——在那裡挑幾張一起按 M 標，是讓 AI 進步最快的地方（以前的「快速標媒材」一次一張視窗 b96 拿掉了，三週只標了 5 張）。大圖「媒材」列上 AI 猜的那格比較淡，滑過看信心，點一下就算確認
- **多準**：開發時用 450 張人工標註做 5 折交叉驗證：只用 WD 約 81%，加上 CLIP 約 85%；有把握的那些約 91%。你的圖庫實際多準要看你標了多少。重新驗證：`/api/diag/eval-media`
- 搜尋：`type:photo`、`type:chibi`、`type:other`（或 `type:截圖`）、`type:unsure`（或 `type:未定`）

## 未識別

「未識別」頁的狀態在標題下（完全未識別、缺角色、缺創作者、多人圖缺角色）：
- **完全未識別**：沒有角色、沒有創作者、也沒有作品（包括原創）。只要標了其中任何一項，圖就會離開這裡，所以已確認作者的非同人作品不會再出現
- **缺角色**：還沒有角色的圖。非同人或原創作品按 **O** 標為「原創」（`original` 作品 tag），之後就不會再出現在這裡
- **缺創作者**：還沒有創作者的圖

標題下的「找出處」打開補跑視窗（範圍預設是未識別）。

點下面的查詢列打開面板，裡面有**分流**，把一大堆圖拆成處理方式不同的幾堆：
- **有 AI 候選**：AI 有猜角色／作品，逐張按是／不是最快
- **沒有候選**：AI 也猜不出來，要靠你自己認
- **還沒搜來源**、**影片**
- **不用整理的**：按 **L**（或 X）「不用整理」的圖。認不出來、也不想再管的圖，選取後按 L：圖留在圖庫、搜尋照樣找得到，只是不再算進未識別的待辦數字。隨時可以在這裡放回待辦
- **分堆**：沒有身分的圖依 AI 看到的內容自動分成「梗圖／截圖、有字的插畫、照片／cosplay、沒有人物、漫畫、插畫」。點一堆會出現說明和整堆處理的按鈕：**全部不用整理＋標「梗圖」**（梗圖、有字的插畫預設）、**全部不用整理**。先捲一遍，把要認角色的圖勾起來，它們會被留下來；一次「撤銷」就能全部還原。分堆只是篩選，不會自動做任何事。實測：梗圖／截圖一堆約九成真的是梗圖或截圖，「有字的插畫」約七成是表情包（也有翻譯過的同人圖，所以要先看），「插畫」裡仍有一兩成梗圖

建議順序：有 AI 候選 → 沒有候選（看一遍，認得的標起來，剩下 Ctrl+A 全選按 L 不用整理）。

## 標籤來源與否決

每個標籤前面都有一個小徽章，標示是從哪裡來的：**D** Danbooru、**P** Pixiv、**AI** WD tagger 模型、**Px** PixAI、**EH** E-Hentai（以前的以圖搜圖、整本匯入）、**手** 手動加的、**⇒** 標籤蘊含帶上的、**dl** gallery-dl 匯入的貼文作者（按住 Alt 看格子上的徽章）。綠底表示已確認。一般描述 tag 會顯示常見的中文對照（設定可以改回英文）。
- **否決會一直有效**：按「不是 X」之後，所有自動來源（模型、比對、Danbooru、Pixiv）都不會再把 X 標回這張圖。同一張圖的其他複本（不同尺寸或格式），以及特徵很像的圖（差分、裁切），上面自動加的 X 也會一起移除，之後新進的相似圖也不會再被自動標上。相似度門檻在設定「否決傳播相似度」（預設 0.9）
- **停止自動標註**：某個標籤一直被模型誤判時，在標籤頁的 ⋯ 選單勾「停止自動標註」，之後這個標籤只會留在你手動標記的圖上。否決次數比確認還多的標籤，頁面上會出現提示
- 「已否決」篩選可以看到所有否決過的圖，按錯了可以取消否決
- **刪除標籤**：標籤頁 ⋯ 選單左下角「刪除標籤」→ 從所有圖上拿掉這個標籤（圖片不動），資料卡、別名一起刪掉。預設勾「以後也不要自動標上」，AI 和 Danbooru／e621／Rule34 之後不會再把它標回來。只是名字不對的話，用「重新命名」或「合併到」比較好（紀錄會保留）
- 以上操作（包括**合併標籤**、**刪除標籤**）都可以用 Ctrl+Z 撤銷

## 標籤蘊含（A 也代表 B）

「確認 A 的圖，自動帶上 B」。最常見的是**造型 ⇒ 本體**：asuna_(bunny)_(blue_archive) ⇒ asuna_(blue_archive)、hakui_koyori_(1st_costume) ⇒ hakui_koyori；也可以自己訂，例如「表情包 ⇒ 梗圖」。
- **Danbooru 的會自動抓**：有確認圖的角色，背景問 Danbooru 有沒有蘊含（只收「角色 ⇒ 角色」；作品 ⇒ 母系列已經由作品頁處理）。新角色存了資料卡也會問
- **角色 ⇒ 所屬作品**（b93）：照角色資料卡的「所屬作品」，確認 togawa_sakiko 就一起確認 bang_dream!_it's_mygo!!!!!、確認 mega_absol 一路帶上 absol、pokemon。否決候選角色時，只因為它才出現的作品**候選**一起收掉（別的角色也屬於那部作品的留著）。資料卡更新時跟著改；不想要的在「也代表」拿掉
- **自己訂、自己關**：標籤頁 ⋯ ›「改名、合併、資料卡」→「也代表」，填標籤名稱（逗號分隔）。拿掉 Danbooru 給的那條＝之後不套用（Danbooru 更新也不會加回來）。程式從名字猜的造型（算人數時當同一個人）猜錯了，勾「跟 ○○ 不是同一個人」
- **套用**：在圖上確認、加上 A 時 B 一起確認（徽章 ⇒），你否決過 B 的不動；按 Ctrl+Z 兩個一起撤銷。否決 A 時，只因為 A 才帶上的 B 一起拿掉。MD5、Pixiv ID 這類自動確認也會套用
- **名字像造型、Danbooru 卻沒說是**（例如女體化的 draco_malfoy_(redteneri)）：照 Danbooru 當成另一個角色，不帶上本體、算人數也分開。要當成同一個人就自己在「也代表…」加上
- **以前確認過的圖**不會自己改：系統 › 工具 › 更多工具 ›「標籤蘊含」看會多幾張，按「套用到 N 張舊圖」才改（一筆撤銷）
- 標籤頁頁首會顯示「也代表：…」；多人圖算人數時，造型和本體只算一個人

## 匯出訓練集（LoRA）

把一批圖複製到一個資料夾，每張旁邊一個同名的 `.txt` 標註，訓練 LoRA 的程式（kohya、OneTrainer…）直接讀得懂。
- 打開：選圖後選取列的「匯出訓練集…」、Ctrl+K 打「訓練集」、系統 › 工具 › 更多工具。範圍可以是選取的圖、這一頁的全部、或一段搜尋（例如 `akiyama_mizuki -tag:梗圖`）
- 標註用**你確認過**的角色、作品、創作者（角色有所屬作品、圖上沒標作品時補上），加上描述標籤（AI 的要分數 ≥ 0.35，可以調；你否決過的不放）。順序：觸發詞 → 角色 → 作品 → 創作者 → 描述（分數高的在前）
- 選項：觸發詞、底線換空格、括號加反斜線（`akiyama mizuki \(project sekai\)`）、用中文顯示名稱、略過 NSFW、要不要放自訂標籤（梗圖這類）。視窗下面會預覽前三張的標註
- 圖片照原檔複製；HEIC、AVIF、TIFF 轉成 PNG；影片不匯出。檔名是圖片編號，再匯出一次會蓋掉同一張
- 不能匯出到圖庫資料夾裡面（會被當成新圖再掃一次）

## 創作者（畫師）

側欄的 **創作者** 頁會列出所有創作者，每位都附別名，以及 Pixiv／X／Fanbox 等連結。
- **手動標記**：選取圖片後按 **R**，輸入名字（輸入新名字就會新建一位創作者）。大圖檢視裡在輸入框打 `a:名字` 也可以
- **自動（搜源）**：「創作者」頁 ≡ ›「缺創作者的圖」→ 選好按「找出處」（補跑）
  - Danbooru 找到的原圖會直接帶出畫師 tag
  - Pixiv 作品會用作者的 Pixiv 網址到 Danbooru 查出對應的畫師名稱；Danbooru 上查不到的，就用 Pixiv 暱稱新建，同一位作者以後會自動對上；Danbooru 之後登記了會自動合併到正式名稱
  - 檔名本身就是 Pixiv 作品 ID 時，作者一定正確，會直接確認
- 在創作者頁的 ⋯ 選單可以手動填寫別名、**編輯連結**（一行一個，可刪可加；手動改過的不會被自動抓取覆蓋，Danbooru 查不到的 wiki 連結不再顯示）；創作者列表 ≡ ›「抓資料」會從 Danbooru 補齊所有創作者的連結
- **同一個作者有兩個身分**（Danbooru 上是兩個畫師 tag、資料不互通，例如換過名字、另開成人帳號）：到其中一個的創作者頁 ⋯ 選單 →「合併到」，填另一個的名稱。兩邊的圖、別名、X／Pixiv 連結都合在一起；舊名稱變成別名，之後 Danbooru 搜源回舊名稱、或從舊帳號匯入的圖，都會自動標成合併後的那位。保留哪個名稱：通常選圖比較多、或 Danbooru 上比較常用的那個。Ctrl+Z 可以撤銷
- 搜尋：直接輸入創作者名稱；`is:noartist` 找出還沒標創作者的圖

## 自動標記與搜源（設定 › 自動標記與搜源）

所有「自動加標籤、自動找出處」的步驟集中在設定的這一類，照新圖真正跑的順序分段：在你的電腦上認（WD、PixAI、你的圖庫、AI 生成提示詞、圖上的簽名）→ Danbooru 同一張（原檔、像素指紋）→ 找相似的圖（IQDB、Pixiv 標籤、Rule34）→ 從網站匯入時（X、Iwara）→ 半自動（ascii2d、畫師作品比對）→ 找到之後（高清版、中文名、資料卡）。

每一步一列，點名字展開：
- **開／關**：左邊的開關（沒有開關的是一定會做的）
- **找到時怎麼辦**：右邊的選單。**直接確認**（還是會尊重你的否決、「不用整理」、梗圖這些規則）／**放待確認**／**只記下**（結果照存、大圖「詳細」看得到，但不加標籤）／**依情況**（X、Iwara：作者直接確認、hashtag 放待確認）
- **門檻**：拉桿；改過的旁邊有「預設 0.85」可以一鍵改回
- **準確度參考**：你在這一步的候選上按過幾次是／不是、對的比例；有分數的步驟（WD、PixAI、IQDB）展開後有一排小柱子：每個門檻下你按「是」的比例，綠色那根是目前的門檻
- 跟預設不一樣的步驟名字旁邊有一個小點；「這一步恢復預設」「全部恢復預設」回到目前實測最穩定的設定（線上功能總開關不動）
- 最下面的「共同規則」：線上功能總開關、新圖自動找出處與預判、找不到隔幾天重搜、找到出處後收掉 AI 角色候選、否決傳播

預設＝改版前的做法：Danbooru 原檔、畫師作品比對直接確認；其他放待確認；PixAI 只記下（評估過再改成放待確認）。

**改了只影響之後找到的。舊圖用「補跑」**（這一類右上、每一步展開後的「補跑這一步…」、選取列打「補跑」、系統頁的「補跑舊圖」、未識別頁的「找出處」都是同一個視窗）：
- **範圍**：選取的圖／目前這頁的條件（例如某個角色頁、某個搜尋）／未識別／缺創作者／還沒找到出處／最近加入的 N 天／搜尋語法（跟圖庫一樣，例如 `is:noartist added:30d`）／整個圖庫；可以不含 NSFW。選了馬上算出幾張
- **步驟**：WD 重新標記、PixAI、AI 生成提示詞、簽名、Danbooru 搜源（可勾「已經找到出處的也重搜」）、Rule34、排進 ascii2d；每一步旁邊顯示這個範圍裡實際要做幾張（只做圖片的步驟不算影片；沒開、沒填 key 的會寫原因）
- 都在背景做，可以關掉視窗；你確認、否決、手動加的標籤不會被改

## 線上資料（Danbooru / IQDB / Pixiv）

**角色資料卡**：新出現的角色會在背景從 Danbooru wiki 抓取資料（約每秒 1 個）。角色書架 ≡ ›「抓名字／資料」可以一次補齊所有角色。
- 所屬作品（例如 `project_sekai`）：顯示在角色名稱下方，點一下就能看該作品的所有圖；角色頁可以選「依作品分組」
- 日文／中文名稱與其他別名（暁山瑞希、晓山瑞希…）：搜尋框直接輸入「瑞希」就找得到
- 簡介，以及 Danbooru wiki 連結
- 抓錯或抓不到（例如原創角色）時，在角色頁的 ⋯ 選單可以手動填寫；手動改過的資料不會被覆蓋

> **強烈建議填 Danbooru 帳號**：沒有帳號時，以圖搜源只能用公開的 IQDB，一張常要 30–60 秒，幾千張要跑好幾天；填了免費帳號的 API key 就能用 Danbooru 自己的相似圖搜尋，快很多。
> [註冊](https://danbooru.donmai.us/users/new) → [API Keys](https://danbooru.donmai.us/api_keys) → Add（權限全部不勾）→ 在首頁的提示或 設定 › 網站帳號 貼上，按「測試」確認。沒設定時首頁、進度膠囊（「慢速」標籤）和診斷頁都會提醒。

**自動搜源**（預設開啟）：新圖、還沒搜過的圖會在背景慢慢搜（新的先），右上角會顯示進度，可以隨時停止；**排隊的工作存在資料庫裡，關掉程式、重開電腦後會接著做**；你手動按的（S、匯入、工具）會插隊到背景補搜前面，角色資料卡也不會被幾百張補搜卡住；找不到的過 30 天會再搜一次（Danbooru 每天都有新圖）。
- **補搜「可能」的圖**：預設「很可能＋可能」都自動搜（設定可以改成只搜「很可能」）；以前只搜很可能時跳過的，收件匣的「之後可以做」會列出預判「可能」、但還沒用以圖搜源找過的張數，點一下在背景補搜（每張 2–3 秒）
- **找不到的定期重搜**：找不到出處的圖每 30 天（設定可改）自動重搜；程式一直開著也會每 6 小時檢查一次。收件匣和系統頁底部顯示下次重搜
- **先預判再搜**（不連網）：看檔名、尺寸、媒材和 WD 描述 tag，判斷「很可能／可能／不太可能」在 Danbooru 上。認得出角色、有畫師簽名或 X 帳號的同人圖優先；梗圖、截圖、照片、本機 AI 圖只做快速的 MD5 比對，不上傳 IQDB。預設「很可能＋可能」都完整搜（設定可改），手動按 S 一定完整搜。重複的圖已經找到來源時直接沿用（當候選，不直接確認）
- **「同一張圖」怎麼判斷**（重複頁、沿用搜源結果、否決傳播都用同一套）：外觀指紋（dHash）差 ≤ 3、長寬比差 ≤ 4%、內容特徵相似度 ≥ 0.85，最後逐像素比對（差分不算），全部都要過。只看外觀指紋會把「白底＋中間一個人」的不同圖當成同一張。而且只沿用確定的結果（原檔 MD5、像素指紋、Pixiv／推文 ID、IQDB）；從畫師反推、簽名這類推測來的結果不會再傳給別張
- **檔名線索**：檔名就是原檔 MD5（Grabber 等下載器）→ 就算檔案被轉存過也能直接對上；檔名是 X 圖片編號（例如 `G3EnWvxa4AAcQYN`）→ 找 Danbooru 上來源是這張圖的貼文
- **截圖**：上傳 IQDB 前會先裁掉四周的單色邊（手機截圖的黑／白底）
- **灰色地帶**：IQDB 70–90% 的結果（截圖、裁切、壓縮常見）會下載 Danbooru 的圖跟你的圖實際比對，夠像才採用
- 真人／公仔照片、本機 AI 生成的圖（ComfyUI、WebUI 輸出）不會上傳 IQDB，因為 Danbooru 上不會有

**以圖搜源（手動）**：選取圖片後按 **S**，或在「未識別」頁點「找出處」（補跑）。會依序嘗試：
1. **Danbooru MD5**：檔案和 Danbooru 上的原檔完全一樣時 → 角色／作品／畫師 tag **直接設為已確認**
1b. **像素指紋**：檔案不一樣、但像素完全一樣（去掉 EXIF、PNG 重新壓縮）→ 一樣**直接確認**。只送出 32 字元的指紋，不上傳圖片
2. **IQDB 相似圖搜尋**：會上傳縮小成 1000px 的圖片；相似度 ≥ 90% 才採用 → 放進**候選**，等你確認
3. **Pixiv**：檔名是 Pixiv 格式（如 `12345678_p0.jpg`），或 Danbooru 的來源是 Pixiv 時，會抓標題、作者和 Pixiv 標籤。Pixiv 上的日文角色名如果對得上角色資料卡的別名，也會建議對應的角色；標為 R-18 的作品會自動標成 NSFW
- **圖站比對（手動）**：大圖檢視的「圖站」列有「e621 原檔」「e621 以圖搜圖」（上傳縮小的這一張，90 分以上才採用；填了 e621 帳號每 10 秒 6 張，沒帳號每分鐘 1 張）「Rule34 原檔」和 Rule34 角色搜尋
- **以圖搜圖（手動）**：大圖檢視「以圖搜圖」列，點了才會上傳這一張。SauceNAO、ascii2d、IQDB 由瀏覽器直接送圖開新分頁（ascii2d 會先跳機器人驗證，點一下即可）；**TinEye、Fluffle（furry 圖專用）由程式上傳，結果直接列在大圖檢視裡**。Google Lens、Bing、Yandex 實測都不接受程式或別的網頁送圖（Lens 結果頁 403、Bing 400、Yandex 擋），放在「其他網站…」：先「下載這張」再把檔案拖進網頁
- 大圖檢視的「來源」區塊有 Danbooru／Pixiv／原始來源連結，每個 tag 都可以按 ＋ 單獨套用，或按「全部套用並確認」
- 找到的「作品」tag 在側欄「標籤」頁瀏覽；創作者有自己的頁面（見上一節）
- 搜尋語法：`series:project_sekai`、`is:unsourced`（還沒搜過來源的）

**ascii2d 半自動找出處**（系統 › 工具、Ctrl+K 打「ascii2d」、或選取圖片後在命令膠囊打「ascii2d」）：手機從 X 存的圖（`IMG_xxxx`）大多是 X 上的原創圖，Danbooru 沒收，自動搜源找不到；ascii2d 找得到，但它有機器人驗證，只能在你的瀏覽器裡由你操作。
- 需要「存到圖庫」油猴腳本（設定 › 從網站匯入 ›「瀏覽器按鈕」；之後 Tampermonkey 會自動更新，腳本太舊時面板會提醒）
- **先選範圍**：選取的圖（命令膠囊打「ascii2d」），或搜尋條件（跟圖庫一樣的語法，例如 `date:2026-07`、`path:2026-07`、`type:comic`、`-tag:梗圖`；下面有依月份的快捷鈕）。預設只排還沒有創作者、ascii2d 還沒找過的，**最多 50 張**（可以改；一次 30–50 張剛好），會即時顯示「符合幾張 → 這次排幾張，**預估找到約幾張、要多久**」（照你過去的找到率和速度算：手機存的插畫約 40%、其他插畫約 13%、漫畫／有字約 8%、梗圖約 2%，每張約 29 秒）。預設換掉目前的佇列，也可以勾「加在後面」；「清空佇列」隨時可以按
- **找到率低的預設不排**：漫畫、有字、沒有人、梗圖、照片。要找的話勾「也找找到率低的」；你自己選取的圖不管找到率，照樣排
- **佇列自己會整理**：排進去以後有了創作者、標成官方截圖、標了梗圖／截圖、按了略過或「不用找作者」的，輪到之前就拿掉，「還剩幾張」是真的還要找的張數。你沒勾「只找還沒有創作者的」特地排進去的圖例外
- **Pixiv 作品被刪、帳號被封**：Pixiv 抓不到作品資料時，用 ascii2d 結果上的作者連結找作者（Danbooru 通常還留著被封帳號的網址；沒登記就用 ascii2d 上的暱稱建立創作者）。其他結果都「不太像」、只剩排在後面的結果比不了（Pixiv 作品被刪、推文被刪、ascii2d 縮圖壞掉）時，一樣自動記「沒找到」；比不了的排在最前面才停下來給你看。比對得上（同一張／很像）但沒有任何標籤可加時，按 Enter＝只記下出處（貼文網址），自動確認也一樣會自己往下走（腳本 2.1）
- **從 X 匯入、Danbooru 沒有的圖**勾了範圍視窗裡的「先找從 X 匯入的」（預設勾起來）才會排在最前面：X 上最大就是你手上那張，同一張圖在 Pixiv 上常常大很多。ascii2d 找到 Pixiv 的同一張時會**馬上比大小**，比較大的話大圖出現「↑ 高清」
- **都不太像就自動跳過**（腳本 1.8 起）：每個結果都比對成「不太像」時，1.5 秒後自動記「沒找到」、送下一張；這 1.5 秒內按任何鍵就停下來自己看。依你的紀錄，不太像的你全部都按了沒找到
- **自動確認**（範圍視窗的「自動確認」，腳本 1.9 起）：選「比對到同一張時」（或「同一張或很像」），比對結果夠準時會把找到的創作者、角色、作品**全部勾起來，1.5 秒後自動按 Enter**；這 1.5 秒內按任何鍵就停下來自己看。預設關閉。全部勾起來包括推文 hashtag／Pixiv 標籤推的角色（平常預設不勾），不放心的話選「同一張」就好，事後也可以 Ctrl+Z 撤銷
- **全自動**（自動確認選「全自動」，腳本 2.8 起）：按一次開始之後不會再停下來等你。平常會停的情況這樣處理：
  - 排第一的結果比不了（作品被刪、ascii2d 縮圖也抓不到）、其他不像 → 記「沒找到」
  - Danbooru 的角色跟你確認過的不一樣 → 收創作者、作品，那些角色不勾
  - 比對過程出錯（連不到 X／Pixiv）、比對太久 → 先跳過（不算沒找到，之後可以再排）
  - 上傳被退回、ascii2d 出錯或太忙 → 等一下自己再送同一張（越等越久），三次都不行就先跳過
  - 連不到 Pickle Jar（程式重開、電腦剛醒）→ 每 30 秒再試
  - 請求沒有回應 → 100 秒後重送；畫面 2 分鐘都沒動 → 自己回 ascii2d 首頁接著做（腳本 3.0）
  - **唯一還要你動手的是 Cloudflare 機器人驗證**（點一下就好，過了會自動接著做）
  - 每次自動決定前一樣有 1.5 秒，按任何鍵就停下來
- **已經確認的角色當證據**（腳本 2.7）：Danbooru 上這篇的角色跟這張圖你已確認的角色一樣 → 標「跟你已確認的角色一樣」，設定「同一張」時「很像」也會自動確認；**不一樣** → 不自動確認，面板上用紅字寫出兩邊的角色，讓你自己看（只是「很像」時那些角色先不勾）。這張圖的角色已經標齊時，hashtag／Pixiv 標籤推的其他角色自動確認也不勾
- 按「開始」打開 ascii2d，右下角出現面板
- **Enter**：腳本向程式要下一張圖，用 ascii2d 自己的上傳表單送出（每次至少隔 4 秒）。Cloudflare 驗證出現時自己點一下，通過後會接著處理
- 結果頁：腳本把 X 貼文、Pixiv 作品、作者的連結送回程式 → 查 Danbooru 有沒有收（有的話角色、作品一起帶出來）、用 FxTwitter／Pixiv 讀作者和標籤、**下載對方的圖跟你的圖比對**
- 面板列出：哪則貼文、比對結果（同一張／很像／不太像／沒辦法比對）、作者和角色。**Pixiv 和 X 都對得上時用 Pixiv**（出處記 Pixiv 作品）；Pixiv 的作者 Danbooru 還沒登記時，作者用同一張圖的 X 帳號補上。比對是同一張或很像的會先勾好；推文 hashtag、Pixiv 標籤推的角色不會先勾（寫了不代表畫的是它）
- **Enter** 確認勾選的並下一張、**1–9** 勾／不勾、**N** 沒找到、**S** 先跳過、**B** 改用特徵檢索（色合検索找不到時）、**Esc** 暫停
- 確認＝你按了「是」：標籤直接算確認（可以 Ctrl+Z 撤銷），出處（貼文網址）記在大圖的來源區塊。X 帳號在 Danbooru 還沒登記時，用 X 帳號建立創作者（跟從 X 匯入一樣，之後登記了自動合併）
- 做到一半關掉也沒關係：排好的圖和已經送回的結果都存著，下次按「開始」接著做；「沒找到」的不會再排，「先跳過」的下次會再排

**找出處**（「未識別」頁標題下的按鈕，或指令面板）：打開「補跑」視窗（見上面「自動標記與搜源」），預設範圍是未識別、步驟是 Danbooru 搜源＋簽名。**新加入的圖會自動做**：Danbooru 找不到時，順便做 Rule34 原檔比對（有填 key）和讀簽名（AI 判斷圖上有簽名的），不用再手動按。
- **像素指紋**：把所有還沒找到出處的圖算出像素指紋（跟 Danbooru 同樣的算法，結果會快取），一次 50 個向 Danbooru 查。只送出指紋、幾乎不耗流量，幾千張約 1–2 分鐘；對上就是同一張圖，不會誤判。實測 3,200 張找回 29 張
- **從畫師反推**（在「更多方法」裡）：從你已確認的畫師出發，下載他們在 Danbooru 上作品的小縮圖（不上傳你的圖），在本機比對：dHash 找候選 → AI 特徵相似度 ≥ 0.55 → 再下載大圖確認相似度 ≥ 0.90 才算找到。可設定畫師數、每位畫師看幾張、流量上限，有「只統計」模式先看效果。流量大、收穫少，所以放在「更多方法」。實測 80 位畫師約 12 分鐘、136 MB，找回 18 張，抽驗沒有誤判
- **讀圖上的簽名**：在本機辨識圖上的 @帳號、X／Pixiv／Fanbox／Skeb／Patreon 網址（第一次會下載約 27 MB 的文字辨識模型），再向 Danbooru 查這個帳號登記在哪位畫師底下——帳號要跟畫師資料裡的網址完全一樣才算。對上的放進「待確認」；**Danbooru 沒登記的帳號只列出來給你參考，不會新建畫師標籤**。只送出帳號文字，不上傳圖片。範圍可選「AI 判斷圖上有簽名的圖」或「所有還沒標畫師的圖」，辨識結果會快取
- **e621 原檔**：furry 圖最大的圖站。用檔案指紋查，一次 100 張、不上傳圖片，不用帳號也能用；b96 起不再自動查新圖（找到率太低），要查在大圖「圖站」列按「e621 原檔」。e621 的標籤有分類：畫師、角色、作品只收 Danbooru 上也有同名的；e621 當成「物種」的寶可夢（lucario）在 Danbooru 是角色，也會對應；公司名（Nintendo、Game Freak）、「conditional_dnp」這類不是畫師的標記不算；自創角色（OC）只列出來參考、不新建標籤。e621 標為 explicit 的自動標 NSFW
- **Rule34 原檔**：用檔案指紋（MD5）查 Rule34 上有沒有同一個原檔（NSFW 圖很多 Danbooru 沒收），不上傳圖片，每秒 1 張。對上的記成出處；Rule34 的標籤是自由填寫的，所以**只有 Danbooru 上也有同名、同類別的畫師／角色／作品才放進「待確認」**，其他的列在來源區塊給你參考、不新建標籤。需要在設定填 Rule34 的 user ID 和 API key（rule34.xxx → My Account → Options）。Rule34 的舊寫法會透過 Danbooru 別名對應（pokemon_sm → pokemon_sun_and_moon），但別名對過去的只收角色／作品、而且 Rule34 自己也要是同一類，Patreon 這類平台名稱不算作品。大圖檢視的「Rule34」列：「原檔比對」查這一張；「搜 畫師 + 角色 ↗」開 Rule34 的搜尋頁讓你自己找（重新存過、截圖的圖指紋對不上時用）
- **準確率抽查**（系統 › 工具 › 更多工具，或指令面板 →「準確率抽查」）：隨機抽 40 張已確認的圖，點出不對的，會算出各種找法的準確率並撤銷標錯的標籤。隱藏 NSFW 模式下只抽看得到的圖

**重新啟動**：指令面板 →「重新啟動程式」（改了區網設定、更新程式後用），頁面會自動重新連上。

選填設定（設定 › 網站帳號）：Danbooru 帳號＋API key 可以提高速率限制；Pixiv `PHPSESSID` cookie 可以讀取 R-18 作品資訊。這些資料只存在你電腦上的 `data/library.db`。也可以完全關掉線上功能，或只關閉 IQDB 上傳。

## NSFW 開關

側欄最下面的 NSFW 狀態或按 **H** 循環切換：**隱藏 → 模糊 → 顯示**（瀏覽器會記住你的選擇）。
- 在「隱藏」模式下，側欄數字、角色封面、搜尋結果都不會出現 NSFW 內容
- 設定裡可以選擇哪些分級算 NSFW（預設 questionable + explicit）
- 選取圖片後按 **N** 可以手動標成 NSFW／安全，手動標記會蓋過模型判定

## PixAI 認角色／畫師（第二個 AI 模型）

WD Tagger 的資料比較舊，新角色常常認不得。PixAI Tagger v1.0（2026-05 的資料）認得 8,308 個角色、4,917 位畫師的畫風，在你的電腦上跑、不上傳。
- 開：設定 › 自動標記與搜源 ›「PixAI」。第一次會下載約 950 MB（有顯示卡用 FP16，只有 CPU 用 INT8 523 MB）；之後背景一塊一塊把整個圖庫跑完（沒有角色的插畫先），新圖也會跑
- 結果先存著，**不會**直接變成候選。跑了一部分之後，系統狀態 › 診斷「PixAI 準確度」（`/api/diag/eval-pixai`）會用你確認／否決過的角色算各門檻的準確度：Danbooru 來的答案模型可能訓練時看過，另外算；你手動、ascii2d、你的圖庫確認的才是真的考試
- 看過評估再把「找到時怎麼辦」改成「放待確認」（同一列右邊的選單；門檻也在這裡拉，旁邊是你按過的是／不是算出來的準確度）：門檻以上的角色、作品、畫師進待確認（0.9 分以上的在「整批看」，其他在 AI 模型分頁，來源標 Px），一律要你按「是」。換門檻不用重跑模型
- 跟 WD 一樣：搜源已經找到的圖、梗圖／截圖、你否決過的，都不會推薦

## 畫師作品比對（Pixiv、X）

已經知道作者的圖很多，但同一位畫師的其他圖常常也在圖庫裡、只是認不出來（手機從 X 存的 IMG_xxxx、截圖）。系統 › 工具「畫師作品比對」：
- **Pixiv**：資料卡有 Pixiv 帳號的畫師，照你收藏的張數排，一次看幾十位。每位抓最新 400 件作品的小縮圖（每頁一張、漫畫最多前 6 頁，約 25 KB）在你的電腦上跟還沒找到出處的圖比對：縮圖夠像 → 下載大一點的版本再比一次 ≥ 90% 才算找到。有填 Pixiv 的 PHPSESSID（設定 › 網站帳號）就看得到 R-18
- 找到的：出處記成那件 Pixiv 作品、**畫師直接確認**（是在他自己的作品裡比到的）；Danbooru 也有這件作品就用 Danbooru 的標籤；Pixiv 標籤對應的角色只放待確認；也會檢查有沒有更高清的版本
- 看過的作品記下來，30 天後再看只看新作品
- **X**：要登入才看得到，所以在你的瀏覽器裡做（油猴腳本 2.6 以上）。打開畫師的「媒體」分頁，圖庫裡有這位畫師時左下角出現「開始比對」：腳本慢慢往下捲、把圖片網址送回圖庫比對。在圖庫的視窗「排名單」再「打開名單第一位」，就會一位接一位自動做（X 有流量限制，一次幾十位就好）

## 資料安全

- **搬家、改名不會掉標記**：每張圖都有內容指紋（MD5）。在圖庫裡搬移、改名會直接接回；程式沒開的時候搬走的，下次掃描時用指紋接回。只有真的刪除的才會顯示「找不到檔案」
- **每天自動備份**資料庫到 `data/backups/`（保留 7 份，設定可改）。還原在 指令面板 →「備份」，會在下次啟動時套用，還原前也會先把目前的存一份
- **備份另存一份**：設定 › 資料與備份 ›「備份另存一份到」選另一顆硬碟、隨身碟或雲端資料夾，每天的備份會再複製一份過去（底下的 `pickle-jar-backups`）。沒設定、或設的跟資料庫在同一顆硬碟時，收件匣會提醒——硬碟壞掉時資料庫和本機的 7 份備份會一起不見
- **備份到外接硬碟**（系統 › 工具 › 維護，或 Ctrl K 打「外接硬碟」）：圖庫資料夾、程式、資料庫整份複製到另一顆硬碟的 `Pickle Jar 備份` 資料夾。插上硬碟按一次就好：
  - 只複製新的和改過的（第一次比較久，之後通常幾分鐘）；備份到一半按「停止」，已經複製的會留著，下次接著做
  - 電腦上刪掉的檔案、內容被改過的舊版，不會馬上從備份消失：先移到 `_刪除保留\日期`，30 天後才清（誤刪、檔案壞掉、中勒索病毒時救得回來）
  - 某個資料夾整個讀不到、或一次少了一半以上（iCloud 同步中、隨身碟沒插）：當成暫時讀不到，這次不移任何檔案
  - 只在 iCloud 雲端、還沒下載到電腦的照片不複製（不會因為備份觸發大量下載）
  - 做完會隨機抽查一批檔案，比對兩邊內容；資料庫快照也會檢查完整性，留最近 10 份
  - 換電腦、整台壞掉時怎麼接回來，寫在備份資料夾裡的 `還原說明.txt`
  - 超過 14 天沒備份，側欄的健康燈會提醒；30 天內備份過，「備份只在這顆硬碟上」的提醒就不會出現
  - 拔硬碟前先在 Windows 右下角「安全地移除硬體」退出
- **刪除可以反悔**：按刪除是丟到資源回收筒，**紀錄保留 30 天**。從回收筒還原檔案（原位置或搬到別處都可以），下次掃描就接回，確認過的角色、作者、否決都還在
- **同一個檔案只記一筆**（b98）：Windows 的檔名不分大小寫，`IMG_1.jpg` 和 `IMG_1.JPG` 是同一個檔案，程式也當成同一張。萬一還有兩筆指著同一個檔案，丟回收筒時只會拿掉多的那筆紀錄，檔案不動
- **找不到的圖可以從出處救回**（b97.2）：檔案不見了（資源回收筒也清了），但搜源找到過出處（Danbooru、Pixiv、X、Rule34）的，可以從出處重新下載原檔、放回原本的資料夾，接回原本的紀錄。會跟程式留著的縮圖逐像素比對，不是同一張的不放
- **資料夾暫時讀不到不會掉標記**：完整掃描時一次有很多張（超過 50 張、而且超過 5%）突然找不到，多半是 iCloud 同步中、隨身碟沒插、網路磁碟斷線，所以先不標成「找不到檔案」；收件匣會問你「確認，真的不見了」或「先不要」。資料夾回來後下次掃描自己恢復
- **匯出／匯入**：把你手動做的確認、否決、NSFW、不用整理、合併、智慧相簿匯出成 JSON（用指紋對應，換電腦也能匯回；你目前的判斷優先，不會被覆蓋）
- **XMP 側車檔**：可以在圖片旁邊寫 `.xmp`（角色／創作者／作品／自訂標籤），Lightroom、digiKam、Eagle 等讀得到。不會改動圖片本身
- **定期完整掃描**（預設每 6 小時）：補上監看漏掉的變動（網路磁碟、電腦休眠）

## 貼出處網址（知道是哪篇貼文）

圖已經在圖庫裡、你知道它是哪篇 X 或 Pixiv 貼文時：
- 大圖 › 詳細（I）› 出處 的「貼網址」，或選好幾張 → 選取列「貼出處網址…」
- 貼上網址就開始比對：程式抓那篇的每一張（Pixiv 多頁最多 40 頁）跟你的圖比，告訴你是**同一張／很像／不太像／沒辦法比對**（對方的圖抓不到時），還有是第幾張／第幾頁
- 對得上的：列出可以帶上的創作者、作品、角色（滑過去看理由）。Danbooru 有收這篇就用 Danbooru 的；沒有就用 X 帳號、Pixiv 作者，和貼文標籤對到的角色——**標籤推的角色預設不勾**（寫了不代表畫的是它）；跟你已確認的角色衝突的也不勾
- 你勾好按 **Enter**：勾的標籤確認、記下出處（大圖的「原貼文」連結）、貼文標了敏感／R-18 的設成 NSFW，網站上比較大的話之後會出現「↑ 高清」。可以 Ctrl+Z 撤銷標籤
- 選了好幾張、貼一篇多張的貼文：每張自動對到最像的那一張。不像的預設不記；確定是的話自己勾「記成出處」
- 只收 X、Pixiv。Danbooru 上的圖用一般的「找出處」（S）就找得到

## 換成高清版

找到出處後，程式會順便看 Danbooru／Pixiv／X／e621／Rule34 上的那張是不是比你的大。**只提醒，換不換你決定。**
- 算「值得換」：長邊多 10% 以上、長寬比一樣（同尺寸的 JPG → PNG 不算）
- 哪裡看：收件匣「N 張在出處有更高清的版本」、搜尋 `is:upgrade`（換過的 `is:upgraded`）、大圖上方的 **↑ 高清**、系統 › 工具 ›「換成高清版」
- 換：大圖 › 詳細 › 來源 ›「換成高清」，或在 `is:upgrade` 清單選好按選取列的「換成高清」（整批是背景工作）。不想換的按「不用換」，之後不再提醒
- 換之前一定**下載下來逐像素比對**（跟重複圖同一個標準）：IQDB 找到的有時是差分（改表情、換字），差分不會換，會顯示「不是同一張」
- 換的時候：新檔放在原本的資料夾、檔名不變（副檔名照新檔，例如 `IMG_1234.jpg` → `IMG_1234.png`），日期沿用舊檔；角色、創作者、作品、標籤、本子頁序全部保留；**舊檔丟到資源回收筒**（從回收筒還原的話，會變成圖庫裡另外一張）
- 貼網址換：大圖 › 詳細 › 來源 ›「換成高清版」貼 X／Pixiv／Danbooru／e621／Rule34 的貼文網址 → 檢查 → 比較大就可以換
- 舊圖補查：系統 › 工具 ›「換成高清版」›「補查 N 張」（有出處、還沒查過的）。新找到出處的圖會自動查，設定 › 自動標記與搜源 ›「找更高清的版本」可以關
- iCloud 照片資料夾裡的圖不能直接換（iPad 上的也會被換掉），先「移出 iCloud」

## 移出 iCloud（省 iCloud／iPad 空間）

想把圖留在電腦、從 iCloud 刪掉：選取圖片 → **移出 iCloud**（大圖檢視也有這個按鈕；搜尋 `is:icloud` 可以找出所有在 iCloud 照片資料夾的圖）。

篩選非動漫圖：搜尋 `is:icloud is:noanime`（Ctrl+K 也有「篩選 iCloud 裡的非動漫圖」指令）。細分：`is:real` 真人照片／Cosplay／公仔、`is:screenshot` 截圖、`is:meme` 梗圖與文字圖；`is:anime` 反過來只看動漫圖。已確認角色的圖（包括動畫截圖）一律算動漫圖。
1. 複製到電腦上的保存資料夾（預設 `圖片\圖庫保存（從 iCloud 移出）`，依年月分資料夾；不能選 iCloud／OneDrive 等同步資料夾）
2. 逐張比對內容指紋，確認一模一樣（iCloud 只放預留位置的檔案會在這一步下載）
3. 圖庫改指向電腦上的那份，**標籤、確認、搜源結果全部保留**
4. 最後才把 iCloud 資料夾裡的那份丟到資源回收筒 → iCloud 同步刪除

任何一張失敗就原封不動留在 iCloud。刪掉的照片會先進 iPad「照片 › 最近刪除」30 天，要馬上釋放空間請到那裡清空。
移出後，首頁會提醒「N 張還在 iCloud 最近刪除」：到 icloud.com → 照片 → 最近刪除，每次選 1,000 張以內刪掉，iCloud 空間才會真的釋放，再按「我清好了」。

在圖庫裡按「刪除」時，如果選到 iCloud 照片資料夾裡的圖，會警告「iPad／iPhone 上也會一起刪掉」，並提供改用移出 iCloud。

## 手機上傳

跟上面〈手機／平板看圖庫〉同一個入口（系統 › 工具 ›「手機／平板」）：手機登入後的頁面有「上傳到圖庫」，照片／影片（包括 iPhone 的 HEIC）存到第一個圖庫資料夾下的「手機上傳/年-月」，自動掃描標記，不用裝 App。

安全：區網只能看圖和上傳，整理的動作、設定、金鑰、備份、匯出都不給；PIN 錯太多次會暫時鎖住。沒開這個功能時，程式只接受本機連線，而且會擋掉假冒 localhost 的網頁（DNS rebinding）。
其他方式：iCloud 可以在 Windows 裝 iCloud 並開啟照片同步，把 iCloud 照片資料夾加入圖庫；Android 可以用 Google Takeout、USB 或 Nearby Share。

## 操作紀錄

系統 › 工具 ›「操作紀錄」：你做過的每個會改資料的操作（確認、否決、加標籤、快速標籤、不用整理、移到回收筒、ascii2d 找到／沒找到、換成高清…）各記一筆，**一直留著**（2 年後才清；撤銷用的紀錄只留最後 100 筆）。
- 看得到：每天幾次、最常做的動作（例如「拿掉梗圖」幾次）、在哪一頁做的、用鍵盤還是滑鼠、撤銷了幾次、幾點最常整理
- 「下載 CSV」：整份紀錄（時間、說明、張數、頁面、鍵盤／滑鼠、有沒有撤銷、圖片編號），Excel 打得開，想自己分析用
- 只記操作本身（說明、圖片編號），不記圖片內容；不會送到任何地方

## 診斷

系統 › 工具 ›「系統狀態」（或系統頁底部的連結、Ctrl K 打「診斷」）：推論裝置（GPU／CPU）、模型檔案、HEIC／影片支援、資料庫大小、備份、監看狀態；可以**測試網路**（Hugging Face、Danbooru、IQDB、Pixiv 連不連得到）和**模型健檢／測速**（輸出是否正常、每秒幾張）；**準確率抽查**（隨機抽 40 張已確認的，點出不對的）也在這裡。

## 整理流程建議

1. **收件匣**：照它說的做（主按鈕按 Enter）——它會依你的圖庫排好先後
2. **待確認 › 整批看**：AI 高分的候選一個名字一面，只挑錯的；再到 **專注** 逐張看剩下的
3. **未識別**：先處理分堆（梗圖堆整堆「不用整理＋標梗圖」），再看「有 AI 候選」，最後「沒有候選」
4. **ascii2d**（系統 › 流程圖那一列「打開」）：手機從 X 存的插畫先找，找到率最高
5. 剩下的：選取後按 **A**（角色）、**R**（創作者）、**O**（原創）手動標；不想整理的按 **L**

## 檔案

- `data/library.db`：SQLite 資料庫（tag、確認紀錄、特徵向量）；每天自動備份到 `data/backups/`
- `tools/`、`.venv/`：start.bat 準備的 Python 和套件（刪掉再執行 start.bat 會重新安裝）
- `data/thumbs/`：縮圖快取，刪了會在重新標記時重建
- `data/errors.log`：程式出錯紀錄（系統狀態看得到）
- `models/`：模型（WD Tagger、PixAI、OCR）
- 操作紀錄存在 `data/library.db` 裡，跟著每天的備份一起備份
- 原始檔案**不會被修改或移動**；只有你按「刪除」（移到資源回收筒）、「移出 iCloud」、「換成高清」時才會動到檔案

## 調整

| 設定 | 預設 | 說明 |
|---|---|---|
| 一般 tag 門檻 | 0.35 | 越高 tag 越少越準 |
| 角色 tag 門檻 | 0.85 | 模型對角色的最低信心 |
| 否決傳播相似度 | 0.9 | 你說「不是 X」後，跟那張圖這麼像的圖也不會再被自動標 X |
| 定期完整掃描 | 6 小時 | 0 = 關閉 |
| 自動備份保留 | 7 份 | |
| GPU 批次大小 | 16 | 16 GB 顯卡可以試 32 |

門檻都在 設定 › 自動標記與搜源。改了模型或門檻以後，用「補跑」選範圍、勾「WD Tagger 重新標記」才會套用到舊圖（你確認過／否決過的 tag 不會受影響）。

## 效能

在約 4,000 張、21 萬筆標籤紀錄的圖庫上實測（v2.5）：側欄 216 → 17 ms、首頁 121 → 17 ms、書架 138 → 26 ms、作品頁 106 → 16 ms、待確認 213 → 10 ms。做法：
- 候選查詢先限定「身分 tag 的 id」，走 (tag_id, state) 索引，不掃過 20 萬筆一般描述候選
- 角色／書架查詢固定從 tag 出發（CROSS JOIN），不讓 SQLite 猜錯順序
- 側欄、首頁的計數合併成一次掃描；名稱轉換（簡繁判斷）和母系列判斷加上快取
- 資料庫用 mmap 讀、頁快取 16 MB；開程式時把 WAL 寫回主檔並截短
- 前端連續操作時側欄更新合併成一次

## 開發與測試

```
pip install -r requirements-dev.txt
python -m playwright install chromium
python -m pytest -q
```

程式資料夾是 git repo：每次更新一個 commit，`git log` 看改了什麼、`git diff` 看差別，出問題可以回到任何一版（`data/`、`models/`、`.venv/` 不在版本控制裡）。畫面測試（用真的瀏覽器把每一頁打開）是必跑的：沒裝 Playwright／Chromium 會失敗而不是跳過。

測試用假的 WD／PixAI 模型（`tests/fakemodel.py`，結構跟真的一樣但很小）和假的 Danbooru／IQDB／Pixiv／e621／Rule34／E-Hentai（`tests/mock_online.py`），不需要網路或 GPU，全部約 210 項約 8 分鐘。涵蓋：掃描與指紋、搜尋語法、否決不會被重新標回、搬家接回、合併撤銷、匯出匯入、智慧相簿、備份與診斷、重複、區網安全與手機、PixAI、搜源優先、ascii2d、本子、換高清、操作紀錄、樣式表（不能有重複選擇器、沒人用的 class、撞名）。

程式結構見 [README › 專案結構](../README.md#專案結構)，模組細節和開發慣例見 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 從網站匯入（X、Pixiv、Danbooru、e621、Rule34、E-Hentai、nhentai，其他網站用 gallery-dl）

看到喜歡的圖，把原圖和資料直接存進圖庫：
- **貼網址**：系統 →「從網站匯入」、Ctrl+K 打「匯入」，或在程式裡任何地方直接 Ctrl+V 貼上貼文網址（一次可以貼很多行，會自動挑出網址）
- **瀏覽器按鈕**：裝 Tampermonkey 後，在匯入視窗裡點「安裝『存到圖庫』腳本」。之後貼文頁右側有「⤓ 存到圖庫」；X 的時間軸上每則有圖的貼文有小按鈕；Pixiv、Danbooru、e621、Rule34 的推薦、搜尋結果、排行榜，滑鼠移到縮圖上右上角會出現「⤓ 圖庫」，不用點進去（腳本 1.3）。存過的會變成「✓ 已存」。腳本裡有一把只屬於你的配對金鑰，別的網站送不進來；可以隨時重新產生
- **E-Hentai、nhentai 整本**（腳本 2.5）：在本子頁按「⤓ 存到圖庫」（列表縮圖上的「⤓ 圖庫」也行），或在程式裡貼網址。整本在背景一頁一頁下載（E-Hentai 每頁約 1.5 秒，網站限速），匯入視窗看得到「下載 12／40 頁」，關掉視窗也會繼續。存在「匯入/e-hentai/標題 [eh123]/001.jpg…」。下載完、標記完會自動建立「同人本」本子：作者／社團、作品、角色變成整本的標籤（Danbooru 對不上的作者／社團用網站上的名字建立）。中途出錯或額度用完，再匯入一次會從中斷的地方接著下載。E-Hentai 抓的是網站顯示的版本（不用登入）；ExHentai 的網址會改用 E-Hentai 抓（只在 ExHentai 上的抓不到）；nhentai 請用瀏覽器按鈕（網站會擋程式直接抓）
- **多張圖的貼文收在小資料夾**：Pixiv 多頁、X 多張會存到「網站/ID 標題/」，單張的照舊放在網站資料夾
- **Pixiv 只存其中幾頁**（腳本 2.0）：多頁作品按「⤓ 存到圖庫」（貼文頁或縮圖上的都一樣）會先跳出選頁視窗，點選要的頁（Shift＋點連選、全選、全不選），按「存選取的 N 張」或 Enter；不想選就按「整篇存」，Esc 取消。在作品頁裡，滑到某一頁大圖上會出現「⤓ 存這張（第 N 頁）」，只存那一頁。在程式裡貼某一頁的圖片網址（右鍵「複製圖片網址」，i.pximg.net 開頭）也只存那一頁。之後再整篇存，只會補還沒有的頁
- 存到 設定 › 從網站匯入 ›「匯入的圖存到」指定的資料夾（空白＝第一個圖庫資料夾裡的「匯入」），底下分 **x、pixiv、danbooru…**；指定的資料夾不在圖庫裡會自動加進去，檔名保留貼文 ID，之後跟新圖一樣自動標記，而且**馬上**找出處（不排在背景佇列後面）
- Danbooru 原檔、X 推文在 Danbooru 上有的 → 角色、作品、畫師直接確認；Pixiv 用作品 ID 查；e621／Rule34 用原檔 MD5 查回原貼文
- X 的 @帳號會對 Danbooru 登記的畫師；Danbooru 還沒登記的，先用 X 帳號建立創作者（例如 later_art，資料卡有 X 個人頁連結，自己搜得到），放進待確認
- **Danbooru 找不到時到其他網站找連結**：新建立的創作者會在背景查 X 個人資料（網站欄、自我介紹裡的 Pixiv／Fanbox／Skeb／Patreon…）、Pixiv 個人資料（社群帳號欄）、e621 同名畫師，把找到的帳號加進資料卡連結；X 和 Pixiv 會互相再查一層。本人填在網站欄／社群欄的帳號如果在 Danbooru 登記了，會直接合併到正式名稱；自我介紹裡的網址、Rule34 名稱在 e621 找到的只當參考連結。手動編輯過連結的不動。手動新增的創作者名字大小寫跟 Danbooru 不同（例如打成 Berull_ogr），Danbooru 有這個畫師就自動合併到正式名稱 berull_ogr（只限創作者；角色、作品同名不一定是同一個，不自動合併）。**手動新增（按 R）的創作者**，Danbooru 查不到時也會用名字去找：名字剛好是某個 X 帳號、或 e621 有同名畫師，就把那邊的連結加進來（只憑名字，可能不是同一人，所以只當參考、不合併）。創作者頁 ⋯ 選單有「從其他網站找連結」可以隨時再找一次。**Danbooru 上有的畫師**（包括 Rule34／e621 對到 Danbooru 名稱的）直接用 Danbooru 畫師資料登記的網址，只收還有效的，X、Pixiv、Fanbox、Skeb 等常用的排前面，已停用的 Pixiv stacc／sketch 不收（以前抓資料時漏了這些網址，已補齊；全部補跑：`POST /api/online/artist-links/all`）。補跑：`POST /api/online/artist-links`（可加 `dry_run`）
- **還沒登記的畫師會自動合併**：用 X 帳號、Pixiv 暱稱、Rule34／e621 畫師名稱建立的創作者，每 7 天問一次 Danbooru，登記了就合併到正式名稱（確認過的圖一起搬過去，舊名稱變別名）。想馬上檢查：`POST /api/online/recheck-artists`。artist_request、anonymous 這類網站上的狀態標記不會變成創作者
- **原貼文網址**：大圖檢視的來源區塊最上面有「⤓ 從 X 貼文匯入 ↗」，點了回到原貼文；檔案搬家後也找得到
- 同一個檔案已經在圖庫就不會再存一次（但會補記這次的貼文網址）
- X 用 FxTwitter 的公開 API，不用登入；Pixiv R-18 要在設定填登入 cookie；Rule34 要先填 API key
- **其他網站交給 gallery-dl**（b84）：Bluesky、DeviantArt、ArtStation、Gelbooru、yande.re、Misskey…（gallery-dl 支援的上百個網站）的貼文網址也可以直接貼。在背景下載，邊下載邊放進圖庫，匯入視窗看得到進度；存在「匯入/網站名稱/」，同一篇好幾張收在小資料夾；圖庫裡已經有的（同一個檔案）不再存一份。貼**整個帳號、標籤、收藏**的網址預設全部抓；設定 › 從網站匯入 ›「整個帳號只抓最新幾篇」可以限制（按篇算，0＝全部）。**同一個帳號再貼一次只抓新的**（下載紀錄在 data/gdl_archive.sqlite3）。Bluesky 的帳號如果在 Danbooru 登記過（或你的畫師資料卡裡有這個連結），會放創作者候選；對不上不會建立新畫師。X、Pixiv、Danbooru 這幾個還是用程式自己的匯入（有選頁、作者這些額外整理，而且 gallery-dl 抓 X、Pixiv 要登入）
- 要登入的網站：在 gallery-dl 自己的設定檔填 cookie（程式會照用）
- 不接付費內容平台（FANBOX 等）和付費內容的轉貼站（Kemono、Coomer）
- gallery-dl 跟著程式安裝（start.bat 會自動裝）；還沒裝的話，匯入視窗會有「安裝 gallery-dl」
- 只替認得的網站下載：上面列的網站，加上 gallery-dl 有專屬支援的網站。任意圖片網址、gallery-dl 的「通用」下載不接
- **網站的標籤**：
  - Danbooru 的一般標籤（雙馬尾、泳裝…）是人工整理的：跟 Danbooru 原檔一模一樣的圖直接用它的（已確認）；AI 猜、Danbooru 沒有、分數又低於 0.8 的收掉（實測 AI 0.9 以上 85% 跟 Danbooru 一致，0.65 以下只有 24–38%；Danbooru 常漏標 blush、smile 這類，所以高分的留著）。相似圖加進來但標「候選」
  - Rule34／e621 的一般標籤：只收 Danbooru 也有的，標「候選」
  - Pixiv 標籤、X 的 hashtag：用 Danbooru wiki 的其他名稱對應角色／作品（暁山瑞希 → akiyama_mizuki），只收「只對到一個」的，放進待確認
  - 你否決過的、停止自動標註的、手動加的標籤都不會被動到
