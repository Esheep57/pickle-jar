# 變更紀錄

新的在上面。

## 1.2（2026-10）

- **简体模式**：設定 › 顯示 ›「中文：繁體／简体」（或 Ctrl K 打「简体」）。不只是簡繁轉換：介面換成大陸用語（文件夹、视频、默认、账号），角色和作品用大陸常用譯名——Bangumi 的原文、維基百科的「大陆简体」標題（电锯人、更衣人偶坠入爱河、间谍过家家）、寶可夢官方簡中譯名；都查不到的才把台灣譯名轉成簡體字。你自己取的名字只轉成簡體字。兩種寫法都搜得到
- 掃描照檔名排序：不同電腦、檔案系統上新圖的編號和處理順序都一樣

## 1.1（2026-10）

- **備份到外接硬碟**：插上硬碟按一次，圖庫資料夾、程式、資料庫整份複製過去（只複製新的和改過的）。電腦上刪掉、被改過的舊檔在備份裡先留 30 天；某個資料夾整個讀不到時不動備份；只在 iCloud 雲端的照片不會被觸發下載；做完抽查內容、檢查資料庫快照，並在備份資料夾寫一份還原說明。超過 14 天沒備份時健康燈提醒。在 系統 › 工具、設定 › 資料與備份、Ctrl K
- 同一個人變成兩個創作者時（兩邊登記了同一個 X／Pixiv／FANBOX 帳號）自動合併

## 1.0（2026-10）首次公開

第一個公開版本。功能見 [README](../README.md)，用法見 [使用手冊](USER_GUIDE.md)。

跟作者自己用的版本相比：
- 拿掉 FANBOX 匯入（含登入 cookie）和 Iwara 匯入；gallery-dl 也不接付費內容平台和付費內容的轉貼站
- 不附起始的媒材標註：先自己標約 40 張（每一種至少 3 張），媒材分類才開始學
- 角色頁（收藏排行、近期新增、作品拼貼）、選取列、預設底色（淡綠）和側欄（完整）是公開版自己的設計
- 開發過程的內部文件（審查報告、部署紀錄）不公開；開發者需要的部分整理在 [DEVELOPMENT.md](DEVELOPMENT.md)
