## 1.0（2026-10）首次公開

第一個公開版本。功能見 [README](../README.md)，用法見 [使用手冊](USER_GUIDE.md)。

跟作者自己用的版本相比：
- 拿掉 FANBOX 匯入（含登入 cookie）和 Iwara 匯入；gallery-dl 也不接付費內容平台和付費內容的轉貼站
- 不附起始的媒材標註：先自己標約 40 張（每一種至少 3 張），媒材分類才開始學
- 角色頁（收藏排行、近期新增、作品拼貼）、選取列、預設底色（淡綠）和側欄（完整）是公開版自己的設計
- 開發過程的內部文件（審查報告、部署紀錄）不公開；開發者需要的部分整理在 [DEVELOPMENT.md](DEVELOPMENT.md)
